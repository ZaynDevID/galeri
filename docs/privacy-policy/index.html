GALERI English

Kebijakan Privasi

Berlaku sejak 3 November 2026 · Diperbarui 3 November 2026

Ringkasnya: Galeri adalah galeri foto dan video lokal/offline. Aplikasi tidak memiliki akun, iklan, analytics, atau izin internet. Foto, video, album, favorit, PIN, dan Sampah tetap di perangkatmu dan tidak dikirim ke mana pun.

1. Siapa yang mengelola aplikasi ini

Aplikasi Galeri (paket com.zayndev.galeri) dikembangkan dan diterbitkan oleh ZaynDev. Pertanyaan tentang privasi dapat disampaikan melalui tombol Email pengembang pada halaman resmi aplikasi di Google Play.

2. Data yang diakses

  • Foto dan video di perangkat. Dengan izinmu, aplikasi membaca file media dari penyimpanan perangkat agar dapat menampilkan, memutar, mencari, dan mengelolanya.
  • Pengaturan aplikasi. Tema, urutan, mode tampilan, favorit, album manual, dan preferensi lain disimpan secara lokal.
  • PIN dan kunci album. PIN disimpan sebagai hash SHA-256 dengan salt acak; PIN asli tidak disimpan. Status kunci album juga disimpan secara lokal.
  • Sampah 30 hari. Saat kamu memindahkan media ke Sampah, aplikasi menyalin file ke penyimpanan privat aplikasi sebelum meminta Android menghapus item asli dari MediaStore. Salinan ini dapat dipulihkan atau dihapus permanen.
  • Log crash. Jika aplikasi mengalami error, ringkasan teknis (termasuk model perangkat dan versi Android) dapat ditulis ke folder aplikasi dan/atau Downloads/Galeri. Log ini tidak dikirim otomatis dan hanya ada di perangkatmu.

Aplikasi tidak mengakses kontak, lokasi, kamera, mikrofon, atau riwayat penjelajahan.

3. Izin yang digunakan

  • READ_MEDIA_IMAGES dan READ_MEDIA_VIDEO (Android 13+): membaca foto dan video.
  • READ_MEDIA_VISUAL_USER_SELECTED (Android 14+): memungkinkan akses hanya ke foto/video yang kamu pilih saat memakai opsi akses terbatas.
  • READ_EXTERNAL_STORAGE (Android 12 ke bawah): membaca media dari penyimpanan.
  • WRITE_EXTERNAL_STORAGE (Android 9 ke bawah): memulihkan media ke folder Pictures/Galeri atau Movies/Galeri.

Izin hanya diminta saat diperlukan dan dapat dicabut kapan saja melalui pengaturan Android.

4. Pengumpulan dan pembagian data

Kami tidak mengumpulkan, menjual, menyewakan, atau membagikan data pribadi. Aplikasi tidak menggunakan SDK iklan, analytics, pelacakan, atau layanan pihak ketiga yang mengirim data. Tidak ada data yang dikirim ke server kami karena aplikasi tidak memiliki koneksi internet.

Fitur Bagikan hanya meneruskan file yang kamu pilih ke aplikasi lain melalui intent Android setelah kamu memicunya. Tujuan berbagi ditentukan olehmu, dan aplikasi tujuan memiliki kebijakan privasinya sendiri.

5. Penyimpanan dan penghapusan

Pengaturan, favorit, album, PIN, dan metadata Sampah disimpan di perangkat sampai kamu menghapus data aplikasi atau menghapus instalasinya. File media asli tidak diubah atau dihapus kecuali kamu memilih aksi hapus dan menyetujui konfirmasi Android. Media di Sampah disimpan maksimal 30 hari, lalu dibersihkan otomatis saat aplikasi dijalankan. Kamu juga dapat memulihkan atau menghapusnya lebih cepat dari menu Sampah.

Menghapus data aplikasi akan menghapus Sampah dan pengaturan lokal. Log crash di Downloads/Galeri dapat kamu hapus sendiri melalui pengelola file.

6. Keamanan

Karena data tidak dikirim keluar perangkat, risikonya terutama bergantung pada keamanan perangkatmu. PIN aplikasi dan kunci album adalah perlindungan UI lokal, bukan enkripsi file media. Kami menyarankan menjaga kunci layar dan mencadangkan file penting secara terpisah.

7. Anak-anak

Aplikasi ini bukan layanan yang ditujukan khusus untuk anak di bawah 13 tahun dan tidak dengan sengaja mengumpulkan data pribadi anak. Aplikasi hanya menampilkan file media yang sudah ada di perangkat atau yang dipilih pengguna.

8. Tautan ke situs lain

Jika kamu membuka tautan atau aplikasi lain, kebijakan privasi pihak tersebut berlaku. Aplikasi tidak mengirim data ke browser atau situs mana pun.

9. Perubahan kebijakan

Jika praktik data berubah, halaman ini akan diperbarui dan tanggal di bagian atas akan diubah. Versi terbaru selalu tersedia di alamat ini.

10. Kontak

Untuk pertanyaan, koreksi, atau permintaan terkait privasi, gunakan tombol Email pengembang pada halaman Google Play aplikasi Galeri. Kami akan menanggapi melalui saluran yang tersedia di listing tersebut.
